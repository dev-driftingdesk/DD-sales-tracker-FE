# SalesTracker CRM

A comprehensive Customer Relationship Management system built with React 19.1.0 and Zustand state management.

## Project Structure

```
📁 SalesTracker/
├── 📁 src/                    # Frontend React application
├── 📁 public/                 # Static assets
├── 📁 backend-docs/           # Backend API specifications and implementation plans
│   ├── API_REQUIREMENTS_SPECIFICATION.md
│   ├── BACKEND_API_IMPLEMENTATION_PLAN.md
│   └── DOTNET_CONVERSION_SUMMARY.md
├── 📁 project-docs/           # Project documentation and guidelines
│   ├── COMPONENT_DOCUMENTATION.md
│   ├── DESIGN_GUIDELINES.md
│   ├── STYLING_GUIDE.md
│   ├── INSTRUCTIONS.md

├── 📁 tests/                  # Testing framework and test files
├── 📁 utilities/              # Utility scripts and tools
├── 📁 archive/                # Archived files and builds
├── 📁 dist/                   # Build output

```

## Quick Start

### Development
```bash
npm install
npm run dev
```

### Testing
```bash
npm test
```

### Build
```bash
npm run build
```

## Key Features

- **Lead Management**: Comprehensive lead tracking and pipeline management
- **Contact Management**: Professional contact organization and communication
- **Deal Pipeline**: Sales opportunity tracking and conversion
- **Analytics**: Real-time sales metrics and reporting
- **Team Management**: User roles and collaboration tools
- **Email Integration**: Built-in email communication system
- **Real-time Notifications**: Live updates and alerts
- **POS Integration**: Point of sale transaction management

## Technology Stack

### Frontend
- React 19.1.0
- Zustand for state management
- Tailwind CSS for styling
- Vite for build tooling

### Backend (Planned)
- .NET 9.0.304
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL database
- SignalR for real-time features
